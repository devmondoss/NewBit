CategoríaNombreVersión recomendadaDescripciónJustificación
Visión por computadorOpenCV+ FFmpeg4.x Biblioteca para leer webcam, MP4 y RTSP, manipular frames y dibujar sobre ellos. Estándar de facto; cubre la captura sin infraestructura pesada y la prueba punto-en-polígono para las zonas.
Detector de objetosUltralytics YOLO nanopersona · casco · sin cascoUltralytics 8.x Detección en tiempo real con entrenamiento y exportación integrados. Liviano: corre sin GPU dedicada; fine-tuning sencillo y exportable a ONNX / TensorRT para edge.
SeguimientoByteTrackincluido en Ultralytics Asigna un ID temporal por persona entre frames, usando detecciones de alta y baja confianza. Habilita ventana temporal, cooldown y deduplicación; resiste mejor oclusiones breves.
LenguajePython3.11+ Lenguaje del motor de visión, el motor de reglas y la API. Ecosistema de visión y ML; un solo lenguaje para el cv-engine y el backend en un equipo pequeño.
Backend / APIFastAPIestable actual API REST con validación (Pydantic) y documentación OpenAPI automática. Rápida de construir y tipada; recibe eventos y sirve configuración e historial.
Base de datosPostgreSQL+ snapshots en disco16 Guarda cámaras, zonas, reglas y eventos; JSONB para polígonos y configuración. Relacional y robusto; camino natural a PostgreSQL + object storage al escalar.
FrontendNext.js14+ Dashboard de eventos, cámaras, zonas, reglas e historial. React con enrutado y despliegue simples; el mismo frontend servirá a multi-sitio después.
ContenedoresDocker Composev2 Orquesta api, base de datos y web en una sola máquina. Entorno reproducible sin Kubernetes prematuro. La webcam en macOS se usa mejor corriendo el cv-engine en el host.
Etiquetado de datosCVAT / Label Studioversión actual Herramientas para dibujar y revisar cajas de persona, casco y sin casco. Exportan en formato YOLO; permiten revisión de calidad de las capturas de planta.
EntrenamientoGPU local o en la nubesegún disponibilidad Cómputo para el fine-tuning del modelo; la inferencia de la demo corre en CPU o Apple Silicon. Entrenar exige GPU, inferir no: se paga cómputo solo durante el entrenamiento.
Gestión ScrumTablero KanbanPor hacer · En curso · Revisión · Hechoherramienta por definir Product Backlog (US-01 a US-06) y Sprint Backlog visibles, con WIP limitado. Hace visible el flujo y el trabajo en curso; Lean evita construir lo equivocado y Scrum organiza la entrega.
Control de versionesGit / GitHubversión actual Repositorio de código, configuración y documentación; pesos del modelo con Git LFS o releases. Revisión cruzada de código y trazabilidad del modelo (pesos + datos + parámetros de regla).
Escalado futuroONNX / TensorRTJetson Orin Nano Super— Modelo optimizado y nodo edge dedicado (GStreamer / DeepStream para video). Solo se justifica cuando crezca el número de cámaras; no es necesario para el primer MVP.
