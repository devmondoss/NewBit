# Índice de documentos

**Regla:** cada archivo que llega (PDF, Word, PowerPoint, imagen) vive en **su propia carpeta, con el mismo nombre**, junto a `<mismo nombre>.md`. Para consultar algo se lee el `.md`; el original solo si el `.md` dice que falta algo.

- **Ficha rápida:** documento largo o escaneado; solo se hojeó. Tipo por defecto para documentos largos.
- **Resumen:** contenido útil (estructura, datos, cifras), no cada palabra.
- **Transcripción:** todo el texto (solo para documentos cortos o formatos a llenar).
- Comprobar que ningún archivo quede sin `.md`: `scripts/verificar-indice.sh`.
